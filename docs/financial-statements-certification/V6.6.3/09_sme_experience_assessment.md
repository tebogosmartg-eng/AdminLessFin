# 9. SME Experience Assessment

**Version:** 6.6.3

## Persona

First-time accountant / bookkeeper familiar with Excel or CaseWare, limited enterprise software knowledge.

## Journey assessment

| Step | SME experience | Result |
|---|---|---|
| Find Financial Statements | Sidebar label Annual Financial Statements | PASS |
| Start engagement | New Annual Financial Statements | PASS |
| Interview | Short engagement questions; entity prefilled | PASS |
| Missing data | Missing Information badges | PASS |
| Generate | One button; progress in plain language | PASS |
| After generate | Engagement Dashboard + Continue Preparation | PASS |
| Navigate work | Accountant sidebar (not modules/engines) | PASS |
| Statements | Finished AFS document titles | PASS |
| Schedules | Accounting topics, not nodes | PASS |
| Notes | Topics, not forced note numbers | PASS |
| Validation | Overall readiness / issues / recommended actions | PASS |
| Review | Manager / Partner / Queries / Sign-off | PASS |
| Publication | Ready / Generate / Download / Archive | PASS |
| Avoid enterprise concepts | IDs/hashes/pipelines hidden from accountant path | PASS |

## Residual risk (accepted)

Advanced internal tools remain available to allowlisted personas for support. SME users without that gate never see them.

## Verdict

SME experience meets certification: interview → generate → prepare → validate → review → publish without enterprise architecture literacy.
