# 8. Validation UX Standard

**Version:** 6.6.3  
**Surface:** Validation

## Accountant language (required)

| Display | Meaning |
|---|---|
| Overall Readiness | Aggregate readiness score / label |
| Critical Issues | Blocking items |
| Warnings | Significant items |
| Information | Advisory items |
| Recommended Actions | Issue recommendation text |
| Ready for Manager Review | Explicit yes / not yet |

## Actions

- **Check again** — re-run validation (existing API)
- **Acknowledge** — record acknowledgement (existing resolve path)

## Forbidden terminology

Validation Engine, run IDs, rule engine codes, and other internal diagnostics must not appear on the accountant surface (Advanced panel retains internal tooling).
