# 04 — Engagement Workflow

**Version:** 6.3.1  
**Board:** Independent Principal Enterprise User Experience Board  
**Verdict:** CERTIFIED  

---

## 1. Purpose

Define the end-to-end **engagement workflow** that makes Financial Statements feel like one reporting engagement aligned to EFCP → Snapshot → EFRE.

---

## 2. Engagement Stages

```
1. Engage     Create/Open workspace
2. Bind       Framework + period context
3. Evidence   Tasks, WPs, Leads (Close)
4. Seal       Create/Certify Reporting Snapshot (+ Freeze when due)
5. Draft      Statements → Notes → Disclosures
6. Assure     Validate → Resolve → Manager → Partner
7. Publish    Approve → Publish
8. Archive    Published pack history / restatement entry later
```

Overview Dashboard Progress maps to these stages.

---

## 3. Pipeline Alignment

| Engagement stage | Architecture owner |
|------------------|--------------------|
| Evidence | EFCP |
| Seal | Snapshot V6.0.1 (orchestrated in workspace) |
| Draft / Assure / Publish | EFRE (+ EFCP reviews as certified) |
| Live inquiry mid-engagement | Accounting Reports (outside workspace) |

---

## 4. Collaboration Pattern

| Role | Stage focus |
|------|-------------|
| Preparer | 3–6 (resolve) |
| Manager | 6 Manager |
| Partner | 6 Partner + 7 |
| Auditor | Read across 3–7 |

Review Notes attach to WPs/leads/statements without leaving engagement.

---

## 5. Exception Paths

| Event | Workflow |
|-------|----------|
| Validation fail needing books change | Task → Accounting journals → new Snapshot → resume Draft |
| Manager/Partner return | Outstanding Tasks + Review Notes; Progress regresses |
| Restatement | New engagement edition / reopen policy per V6.0.1 — new snapshot lineage |

---

## 6. Multi-Framework / Multi-Company

| Concern | Behaviour |
|---------|-----------|
| Framework | Selected per engagement; drives Draft checklist |
| Company | Workspace isolation by tenant; switch company exits/reloads list |
| Comparative | Prior published/snapshot pinned in Draft — not live GL rebuild |
