# First Journal Walkthrough

**Prerequisites:** Accounting Ready.

Manual journal entries are for **adjustments, accruals, and corrections**. Day-to-day sales and purchases normally post via invoices and bills.

---

## When to use a manual journal

- Month-end accruals  
- Depreciation adjustments (if not automated)  
- Reclassification between accounts  
- Opening balance corrections (after migration)  

---

## Steps

### 1. Open Journal Entries

Go to **Accounting → Journal Entries** → **New Entry**.

### 2. Enter header

- **Date** — must fall within an open financial year  
- **Description** — clear reference (e.g. "Accrual — March rent")  

### 3. Add lines

Each journal must **balance** (total debits = total credits).

Example — accrue R10,000 rent expense:

| Account | Debit | Credit |
|---------|-------|--------|
| Rent Expense | 10,000 | |
| Accrued Expenses | | 10,000 |

Select accounts from your Chart of Accounts for each line.

### 4. Save

The entry posts through the certified posting engine. Status shows as **posted**.

### 5. Verify

1. **Trial Balance** — both accounts reflect the movement  
2. **General Ledger** — drill into either account for the journal line  
3. Double-click the journal row to view journal lines  

---

## Tips

- Start with invoices and bills for routine activity  
- Use the AI assist in the journal form for drafting (optional)  
- If save fails, check that Accounting Ready is complete and the date is in an open period  

---

## Common issues

| Issue | Resolution |
|-------|------------|
| Journal Entries blocked | Complete Accounting Setup |
| "Unbalanced" error | Ensure debits equal credits |
| Account not in list | Verify Chart of Accounts is generated |
