# First-Day Checklist

Use this after **Accounting Ready** is achieved. The dashboard **Getting Started Checklist** tracks the same items automatically.

## Morning — Foundation (if not done)

- [ ] Accounting Setup at 100% (all six steps complete)
- [ ] At least one tax rate configured (VAT 15% or your jurisdiction)
- [ ] Chart of Accounts generated (standard template)

## Midday — Master data

- [ ] Company logo uploaded (Settings — optional)
- [ ] Company address set (Settings — appears on invoices)
- [ ] First customer created
- [ ] First supplier created

## Afternoon — First transactions

- [ ] First sales invoice created and posted
- [ ] First supplier bill recorded
- [ ] Trial Balance reviewed — debits equal credits
- [ ] Financial Statements generated (P&L, Balance Sheet, Cash Flow)

## End of day — Verification

- [ ] Trial Balance shows expected AR/AP balances
- [ ] No validation errors on Accounting Setup
- [ ] Dashboard Getting Started Checklist complete

## If stuck

Open the [Onboarding Guide](./ONBOARDING_GUIDE.md) or [Troubleshooting](./TROUBLESHOOTING.md) guide.
