# 03 — Export Standard Report

**Version:** 3.6.5  
**Module:** `src/reporting/export`  
**Product:** AdminLess Fin

## 1. Standard

Every platform report export must follow the same enterprise branding standard. No report may be exported without branding when invoked from the browser UI.

## 2. Format requirements

### PDF

- Company logo when URL fetchable; otherwise AdminLess Fin wordmark text
- Report title, company, financial year, period
- Generated By, Generated Date, Report ID
- Sectioned body support (VIP employee pages)
- Footer on every page + page numbers (`Page N of M`)

### Excel (SpreadsheetML `.xls`)

- Sheet **Working Paper**: branded heading + sectioned (or flat) body; frozen panes; landscape print layout
- Sheet **Detail**: flat rows with header freeze + AutoFilter
- Company / product / report metadata in heading block

### CSV

- No logo (format limitation)
- Professional filename (e.g. `AdminLess-Fin-VIP-Report-FY-2026-27.csv`)
- Leading `#` metadata preamble: product, company, title, FY, period, generated by/date, report id, footer

### JSON

- Branding embedded under `meta.branding` when supplied

## 3. Facade API

```ts
exportReportRows(rows, {
  format, fileBaseName, branding,
  sections?, detailRows?,
})
exportReportRowsAsync(...) // PDF with logo fetch
```

Payroll thin wrapper: `exportPayrollReportRows` / `exportPayrollReportRowsAsync` in `src/lib/payrollReportExport.ts`.

## 4. Call sites updated (platform)

- `/audit-compliance-reports` (VIP)
- `/payroll-reports` (management / statutory / operational Excel-PDF path)

## 5. Residual (documented)

Legacy page-level `downloadCSV` outside the reporting platform (accounting lists, etc.) is **out of scope** for V3.6.5 and remains a residual for a later platform migration.

## 6. Verdict

**CERTIFIED** — Platform export standard owns branding for CSV / Excel / PDF.
