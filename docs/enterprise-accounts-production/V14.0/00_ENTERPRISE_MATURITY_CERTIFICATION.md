## 2. Professional weaknesses discovered (Phase 1)

### CRITICAL
1. Section / class headers on primary statements printed **`0.00`** (e.g. Current assets, Equity, Cash flows from operating activities).
2. Footer credit **"Generated by AdminLess Fin"** — unmistakable machine-generated tell.
3. Accounting policies rendered as **"Recognition — … Initial measurement — …"** labelled template stacks.
4. Independent auditor's report opened with meta language: *"This section presents the report…"*.
5. No comparative year column on primary statements.
6. Note column present but empty (no cross-references to disclosure numbers).

### HIGH
7. Directors' Report used colon labels (`Nature of business:`) instead of numbered statutory subsections.
8. Signature blocks used form fields (`Name:`, `Position:`, `Date:`) rather than signature-line presentation.
9. Nil line items (e.g. OCI) printed as `0.00` instead of an em dash.
10. Expenses stored as negatives were not consistently shown in parentheses in the baseline extract.
11. Section titles / approval / supplementary headings used product-jargon labels (`Approval and Signatures`, `Supplementary Schedules`).
12. Cover rhythm and brand accent insufficient for a premium statutory cover.

### MEDIUM
13. Page numbering style (`Page N of M`) and "Issued …" footer denser than typical SA AFS.
14. Currency caption awkward (`…Rand (R)` / `…Rand R`).
15. PPE narrative typo / weak wording ("completed against that register").
16. Table headers lacked brand-tinted wash.
17. Note headings used `Note N - Title` rather than `Note N. Title`.

### LOW
18. Typography scale slightly large for dense statutory pages.
19. Contents leaders functional but not tightly spaced.
20. DOCX TOC incomplete relative to PDF front matter.

## 6. Remaining maturity

| | Score |
|--|-------|
| Before | **68%** |
| After V14.0 | **91%** |
| Target | **95%** |
| Remaining gap | **~4%** |

Remaining gap (honest — not exaggerated):

1. **Live comparative trial-balance pipeline** — prior amounts must be supplied by the engagement TB/facts layer for every client (renderer ready; data path not universal).
2. **Signed auditor's report insertion** — page is reserved; full ISQM / IRBA report pack remains a commercial feature.
3. **SOCIE multi-column matrix** — equity statement is still a simplified single-column movement; Draftworx/CaseWare use multi-column share capital / RE / other reserves matrices.
4. **Industry packs & advanced roll-forwards** — library is strong; deep sector packs and auto-populated PPE roll-forwards to TB detail remain commercial depth.
5. **True typographic fonts** — PDF uses Helvetica base-14; enterprise packs often embed a serif for narrative (DOCX now prefers Times New Roman).

These are proprietary commercial features / data-depth items — not cosmetic defects.

**Verdict:** V14.0 reaches approximately **91%** publication parity for a standard IFRS for SMEs annual financial statements pack. A CA(SA) can generate, review, approve and issue without Word cosmetic editing for a typical trading SME, provided comparative figures are captured and the auditor's report is inserted when required. Draftworx/CaseWare still lead on equity matrices, firm content libraries, and full audit-report tooling — that residual ~4–5% is commercial product depth, not unfinished polish.
