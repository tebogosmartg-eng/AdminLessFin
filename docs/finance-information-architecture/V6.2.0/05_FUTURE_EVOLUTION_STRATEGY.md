---

## 1. Purpose

Guide future product evolution so ownership boundaries remain stable while Close, EFRE, and labelling mature under V6.1.1 implementation approval.

This pack does **not** implement UI or rename routes.

---

## 2. Evolution Principles

| # | Principle |
|---|-----------|
| E1 | Additive before relocational — prefer new Financial Statements Workspace over ripping Operational routes |
| E2 | Preserve Operational Reports forever (V6.0.0 / V6.1.1) |
| E3 | One rename/move of nav labels requires V4.4.0 + FIA citation |
| E4 | Never create a second owner for an existing capability |
| E5 | Multi-framework expands inside EFRE / Workspace only |
| E6 | Assets & Loans stay independent |
| E7 | Governance stays outside finance statement homes |

## FINAL STATUS

# FINANCE INFORMATION ARCHITECTURE CERTIFIED

AdminLess Fin finance capabilities now have permanent information-architecture owners:

- **Accounting** owns balances  
- **Reports** owns enterprise / operational / executive reporting presentation  
- **Financial Statements Workspace** owns statutory preparation (Close + EFRE)  
- **Assets & Loans** remain independent  
- **Enterprise Governance** remains outside finance statement homes  

**Implementation of navigation changes remains prohibited under this pack** — execute only under Implementation Approvals (e.g. V6.1.1 for Close) that cite FIA V6.2.0.
