# Governance Decision

Effective immediately:

## The Payroll Export architecture is frozen.

This means:

- No redesign of the payslip generation workflow.
- No redesign of the bank export workflow.
- No redesign of the export architecture.
- No redesign of the data mapping architecture.
- No replacement of Edge-authoritative `bank_rows` with client-side reconstruction as the primary path.

Future development must preserve backward compatibility for finalized runs, bank batch metadata, and CSV/PDF consumers.

---

# Certified Architectural Principles

The following principles are permanently adopted unless superseded by a future Architecture Decision Record (ADR).

## Principle 1 — Edge Function is source of truth for bank payment rows

`GENERATE_BANK_BATCH` on the Payroll Edge Function returns authoritative `bank_rows` assembled from employee master data and payslip net pay.

The frontend consumes `bank_rows` directly when present.

## Principle 2 — Fallback is emergency-only

Client reconstruction from `GET_RUN_DETAIL` / payslip embeds is permitted **only** when the Edge Function is unavailable or omits `bank_rows` (legacy deploy / outage).

Fallback must not be treated as the happy path.

## Principle 3 — Employee master owns banking fields

Bank name, branch code, and account number originate from `employees` master data.

Export serializers must not invent banking values. Blank export cells are correct when master values are null.

## Principle 4 — Employer branding on payslips; AdminLess Fin in footer only

Payslip header uses employer logo/name/address.

AdminLess Fin branding appears only as a subtle “Generated by” footer signal.

## Principle 5 — No payroll calculation changes under this freeze

Export certification does not authorize changes to statutory calculations, posting, or run lifecycle logic.

---

# Allowed Changes (no new ADR)

- Legislative updates affecting payslip/bank presentation labels or required columns
- Banking format changes (additive formats / column order mandated by banks)
- Bug fixes
- Security improvements
- Performance optimisation
- Documentation
- Automated tests and certification maintenance

---

# Prohibited Without a New ADR

- Redesign of payslip generation workflow
- Redesign of bank export workflow
- Redesign of export architecture
- Redesign of data mapping architecture (including moving bank-row authority off the Edge Function)
- Breaking changes to `GENERATE_BANK_BATCH` response contract for `bank_rows`
