# AdminLess Fin

**Less Admin. More Growth.**

AdminLess Fin is an AI-powered financial operating system that unifies accounting, invoicing, payroll, and reporting for modern businesses.

## Development

See [docs/DEVELOPMENT.md](docs/DEVELOPMENT.md) for local setup, environment variables, and Supabase edge function deployment.

```bash
npm install
npm run dev
```

## Branding

Product branding is centralized in `src/config/brand.ts` and `src/components/brand/`. Update those files when launching additional AdminLess products (Edu, HR, Pay, Stock).
